sept 16

"As long as you can do the forward pass and the backward pass, it doesn't really matter what the operation is." The end of "building micrograd" was so so interesting. It was kind of fun in a way to see how Karpathy would implement certain functions, such as division, for this scalar-valued NN library - it almost felt like creating a new language within the framework of Python. After a certain point, we can start utilizing normal functions like sum over the neurons but then get out objects that let us run backprop in a way that is much simpler than I would've thought. The loss function itself can be represented as a network of nodes (since, in this example, it is just sum of squares of the distances to the target values) and we can then run backprop on THAT network to find the gradient with respect to the loss value. In trying to predict what he was going to do next, I was thinking that maybe we would have to increment each parameter by the gradient times the distance between each output's predicted value and target value, but this is so much more elegant and logical. Now I finally have a frame of reference for what gradient descent looks like from a programmatic perspective.
